# Project visuals

These images represent the actual projects rather than stock photography.

- `bnb-*.webp`: screenshot of the live BNB Manager account entry screen at
  `https://davaicoop-bnb-manager.onrender.com/`. No account or operational records are shown.
- `bvk-*.webp`: screenshot of the real BVK home page at
  `https://bvk-adult-foster-care-0k12.onrender.com/`.
- `portfolio-*.webp`: screenshot of the existing production portfolio at
  `https://david-korir-portfolio.onrender.com/`. Production is preserved while
  this refinement is reviewed on the feature branch.
- `davai-workflow.svg`: an original illustration of the workflow examples in
  `davaicoop/davai-automation`, branch `feature/automation-agency-mvp`.
  It uses the project's navy/orange palette. It is labelled an illustration,
  not a screenshot or a claim of connected CRM or messaging integrations.

Screenshots have 560px and 1008px WebP variants, responsive `srcset`, explicit
dimensions, asynchronous decoding and lazy loading. Each large image is under
32 KB. The enterprise card retains a labelled workflow illustration because
there is no public application or authorized enterprise screenshot.
